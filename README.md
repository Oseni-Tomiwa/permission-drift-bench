# Permission Drift Bench

Permission Drift Bench is an AI safety benchmark under development for studying whether tool-using AI agents improperly retain, reuse, or expand permissions across multi-step tasks. It evaluates existing models through APIs; it does not train a new model.

The benchmark is sandbox-only. All tools, resources, and data are simulated or synthetic, and benchmark tools perform no real external actions or host-filesystem access.

**Status:** Early v0.1 pilot-stage development.

> **Warning:** No validated benchmark results exist yet. Pilot outputs are integration and design artifacts and must not be interpreted as research findings.
